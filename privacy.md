# Privacy

This website does not use accounts, analytics, advertising scripts, or tracking cookies.

The wishlist is stored locally in the user's browser using `localStorage`.

Data stored locally:

- selected skin IDs;
- skin names;
- weapon names;
- image URLs;
- rarity info.

This data is not sent to the site owner because the site has no backend.

If external skin images are loaded from third-party domains, the browser may request those images directly from the third-party host.
